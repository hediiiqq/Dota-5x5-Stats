# Dota Stats

Учебный проект на Go для статистики приватных матчей Dota 2 своей группы игроков.
Сейчас реализованы HTTP API на локальном примере матча и отдельная утилита авторизации в Steam.

## Что уже сделано

- [x] Модели матча и игроков: K/D/A, экономика, предметы, урон и другие показатели.
- [x] Чтение JSON матча и преобразование данных в формат API.
- [x] Проверка состава матча: ровно 10 игроков.
- [x] Три GET-маршрута: проверка сервера, список матчей и отдельный матч.
- [x] JSON-ошибки для неверного ID и отсутствующего матча.
- [x] Параллельная авторизация двух Steam-аккаунтов с подтверждением через Steam Guard.
- [x] Сохранение и повторное использование токенов, таймауты и обработка событий Steam.

## Требования

- Go 1.27 или новее — версия указана в `go.mod`.
- Для утилиты Steam: два аккаунта с подтверждением входа через мобильное приложение и доступ к сети Steam.

Все команды выполняются из корня репозитория.

## Запуск HTTP API

```sh
go mod download
go run .
```

Сервер слушает порт `8080`. При запуске он читает `testdata/match.json`, преобразует данные и хранит один матч в памяти с внутренним ID `1`.

| Метод | Маршрут | Результат |
| --- | --- | --- |
| GET | `/api/health` | Проверка сервера: `{"status":"ok"}` |
| GET | `/api/matches` | Список загруженных матчей |
| GET | `/api/matches/1` | Матч с внутренним ID `1` |

Откройте [список матчей](http://localhost:8080/api/matches) или [матч № 1](http://localhost:8080/api/matches/1) в браузере.

Для `/api/matches/{id}` неположительный или нечисловой ID возвращает `400` с кодом `invalid_match_id`, отсутствующий матч — `404` с кодом `match_not_found`.

Внешние идентификаторы передаются строками, время начала — в UTC, отсутствующие показатели — как `null`. Победитель (`winner`) пока тоже равен `null`.

## Запуск утилиты Steam

Создайте `.env` в корне проекта и заполните данные двух аккаунтов:

```dotenv
ACCOUNT1_USERNAME=your_first_login
ACCOUNT1_PASSWORD=your_first_password
ACCOUNT2_USERNAME=your_second_login
ACCOUNT2_PASSWORD=your_second_password
```

Названия переменных соответствуют текущей конфигурации в `cmd`. Их также можно задать через переменные окружения.

```sh
go run ./src/cmd
```

При первом входе подтвердите авторизацию в мобильном приложении Steam. Утилита сохраняет токены в `ACCOUNT1_TOKEN.txt` и `ACCOUNT2_TOKEN.txt` и использует их при следующих запусках. Общий таймаут работы каждого аккаунта — 5 минут, авторизации — 180 секунд.

После успешного входа утилита отключается. Получение матчей через Dota 2 Game Coordinator пока не подключено к HTTP API.

**Перед публикацией на GitHub исключите из коммита `.env` и файлы `*_TOKEN.txt`: они содержат пароли и токены доступа.**
