# Профиль игрока для балансировщика

`GET /api/players/{account_id}/profile` — Account ID, положительный uint32
без ведущих нулей. Тело ответа: `id` (строка), `name`, `avatar` (HTTPS URL
или null), `rankTier` (11–75 с допустимыми звёздами, 80 или null), `source`
(`opendota` либо `stratz`). MMR не возвращается: интерфейс оценивает его по медали.

Основной источник — OpenDota, тайм-аут 6 секунд. При сети, тайм-ауте, HTTP 429,
5xx или некорректном ответе используется STRATZ GraphQL с тайм-аутом 8 секунд.
После временного отказа OpenDota следующие запросы минуту идут сразу в STRATZ;
затем снова проверяется OpenDota. HTTP 404 не запускает fallback. Если API
успешно вернул профиль без ранга, значение остаётся null.

`STRATZ_TOKEN` читается сервером из окружения (`.env`). Токен не передаётся в
браузер, upstream-ошибки не возвращаются дословно, перенаправления запрещены.
Без токена OpenDota работает; при её отказе возвращается 503 с указанием,
что резерв не настроен. После изменения токена требуется перезапуск сервера.

Запросы провайдеров сериализованы с интервалом минимум 1,1 секунды между
началами запросов профилей. Общий бюджет, включая очередь, — 20 секунд.
Ответы не кешируются (`Cache-Control: no-store`). Браузер хранит последнее
значение и источник по прежним правилам свежести — пять минут.

Ошибки в стандартном формате `error.code/error.message`: неверный ID — 400,
профиль не найден — 404, оба сервиса отказали/STRATZ отклонила доступ — 502,
резерв не настроен — 503, общий тайм-аут — 504. Отмена клиентом не запускает
резервный запрос. Только GET/HEAD; остальные методы — 405.
